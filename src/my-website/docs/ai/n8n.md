# N8N

N8N 是一款開源且具高度擴展性的視覺化流程自動化工具（Workflow Automation Tool），允許使用者透過拖拉節點、串接 API 來連結各種網路服務（如 Gmail、Slack、Notion）與 AI 應用，打造自動化工作流，適用於處理重複性任務，常被視為高自由度、低成本的 Zapier 替代方案。

## 主要特色與優勢
* 開源與自主部署： 採用 Fair-code 授權，可以自行部署（Self-hosted）在伺服器上，數據隱私完全掌控，且無任務執行數量限制。
* 視覺化節點編輯： 透過「拖拉」操作節點串聯流程，介面直觀，即使無程式背景也能上手，但對工程師來說亦能輕鬆處理複雜邏輯。
* 強大整合能力： 支援超過 400 種熱門應用程序，並能輕鬆整合自定義的 Webhook 和 API。
* 成本效益高： 相較於按使用次數計費的工具，自行部署的 n8n 可以節省大量的月訂閱費用。
* 高邏輯自由度： 擅長處理複雜邏輯、數據轉換、分支條件和迴圈等作業。

## 適用場景
* 表單自動化： 例如 Google 表單提交後，自動在 Notion 建立項目並發送 Slack 通知。
* 數據同步與整理： 自動將 CRM 數據匯出、清理並存入雲端數據庫。
* AI 應用串接： 串接 OpenAI、LangChain 等建立智能自動化工作流。
